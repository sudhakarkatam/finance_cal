# 💰 Financial Calculators PWA  
*A modern, mobile-first finance companion to calculate your thoughts about investing*


---

## 🚀 Overview  

**Financial Calculators PWA** is a comprehensive **mobile-first financial calculator** built with **React, Vite, and Capacitor**.  
It helps you calculate **Simple Interest, Compound Interest, SIP, Mutual Fund Returns, and SWP** — all through a beautiful, intuitive, and responsive interface.

> 🧠 *Finance doesn’t have to be boring — make it visual, interactive, and fun!*

---

## ✨ Features  

### 🧮 Multiple Calculators  
- Simple Interest Calculator  
- Compound Interest Calculator  
- SIP (Systematic Investment Plan) Calculator  
- Mutual Fund Returns Calculator  
- SWP (Systematic Withdrawal Plan) Calculator  

### 📱 Mobile-First Experience  
- Native Android/iOS app feel powered by **Capacitor**  
- **PWA support** (works in browser or installable)  
- Fully **responsive** and **touch-optimized**  
- Inspired by **Material Design**  

### 💾 Offline Storage  
- Save your calculations with **custom notes**  
- **View history** of past entries  
- Works **100% offline** — no internet required  

### 📊 Visual & Interactive Results  
- Real-time calculations  
- Interactive **donut charts** for clarity  
- Clear breakdowns of **principal**, **interest**, and **maturity**
